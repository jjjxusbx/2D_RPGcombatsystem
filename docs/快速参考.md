## 🏗️ 架构速查

### 四层架构

```
Composition Root (PlayerCombatBootstrap)
  ├─ 数据层: ChaState / Attribute / SkillData
  ├─ 决策层: PlayerInputReader / CombatDecisionComponent
  ├─ 表现层: PlayerAnimationPresenter
  └─ 执行层: CombatStateMachine / SkillExecutor / MonsterPatrolController
```

**单一装配入口**: `PlayerCombatBootstrap.Awake()`

---

### Combat FSM（5 状态）

```
IdleState ──→ MoveState (移动)
   │              │
   ├────────→ AttackState (攻击)
   │              │
   ├────────→ DodgeState (闪避)
   │
   └────────→ CastBuffState (技能)
```

**新增（v0.2）**: `JumpState`（跳跃）

---

### Roguelike 房间流（v0.1.5）

```
StartRun()
  ↓
Combat × 3 → Altar（三选一强化）
  ↓
Combat × 3 → Altar
  ↓
Combat × 3 → Boss
  ↓
Settlement（结算 → 晶核持久化）
```

**控制器**: `RogueRoomFlowController`
**管理器**: `RunManager`
**持久化**: `RunCurrencyStore`（版本化 + 原子写）

## 🐛 常见问题

### FSM 不触发

```
检查点:
1. [Diagnostics] 是否有装配日志？
2. CombatStateMachine.Configure() 是否被调用？
3. 基础移动.useCombatStateMachine = true？
4. 跳跃射箭 是否被禁用（v0.2 前）？
```

### 动画参数缺失

```csharp
// ❌ 直接 SetTrigger
animator.SetTrigger("Attack");

// ✅ 使用存在性守卫
PlayerAnimationPresenter.SetTriggerIfExists(animator, "Attack");
```

### 怪物不巡逻

```
检查点:
1. MonsterPatrolPath 是否有路径点？
2. NavMeshSurface 是否烘焙？
3. 敌人是否有 Rigidbody2D + Collider2D + NavMeshAgent？
4. detectionRadius / attackRange 是否合理？
```

### 速度冲突（双写）

```
现状: 基础移动 已让权，跳跃射箭 已禁用（v0.1.1 仲裁）

若出现: 检查 PlayerCombatBootstrap 仲裁逻辑
```

### 闪避后卡死

```
✅ 已在 v0.1 修复: DodgeState.CanTransitionTo 包含 IdleState

若复发: 检查是否修改了 DodgeState 转换逻辑
```
