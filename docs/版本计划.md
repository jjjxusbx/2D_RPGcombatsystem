## 版本计划维护规则

1. 每版结束必须完成复盘模板，未完成不得进入下一版。
2. 验收清单是硬门槛：两个 csproj 构建通过 + 对应 Play Mode 清单，缺一不可。
3. 涉及架构/管理器变更时，先按《用户规则》对抗式审查协议输出"事实/风险/结论"，再决定复用、修复或重写。
4. 文档间引用：本文件 ↔《核心框架设计.md》验收清单 ↔《策划流程与双档方案.md》双档方案 ↔ GDD 数值表。
