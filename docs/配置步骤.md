配置步骤清单（Unity 层级与资源）
场景根：新建空物体 RunManager，挂 RunManager.cs。默认系数即可。
玩家：确认玩家根节点 Tag 为 Player 且带 ChaState（PlayerCombatBootstrap 会自动补挂）。
敌人预制体：现有怪物根节点上需同时具备 EnemyBase + ChaState + MonsterPatrolController + Rigidbody2D + Collider2D + NavMeshAgent（MonsterPatrolController 的 RequireComponent 会强制）；MonsterPatrolController 的 playerMask 记得勾选 Player 层。存成预制体。
碎片预制体：Sprite 子物体 + CircleCollider2D（IsTrigger）+ FragmentPickup，amount 设 1~5。
每个房间：房间根节点挂 BoxCollider2D（IsTrigger，覆盖房间边界）+ RoomFlowController：
战斗房：enemyPrefab 填敌人预制体，spawnPoints 填生成点，fragmentDropPrefab 填碎片预制体。
祭坛房：roomType = Altar；房间内建 Canvas（Screen Space Overlay）+ 空物体挂 AltarUIHandler。
BOSS 房：isBossRoom = true。
出口解锁：每个房间根下建子物体 ExitUnlock（初始 SetActive(false)，比如门/传送点），清理后自动激活。
流程连线（Inspector 的 onRoomCleared UnityEvent）：
普通房清理 → 下一个房间的 RoomFlowController.StartRoom()；
BOSS 房清理 → RunManager.EndRun(true)；
玩家死亡 → 角色死亡回调里调 RunManager.EndRun(false)。
首次运行：先手动调一次 RunManager.StartRun()（或做一张"开始界面"按钮调用），否则强化源为空但碎片计数从 0 开始，流程仍可跑通。
