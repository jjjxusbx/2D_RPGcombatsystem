## 三、功能测试

### 3.1 怪物巡逻系统（静态验证 + Play Mode 手测清单）

状态机逻辑静态核查结论：

| 场景 | 预期 | 代码核查结果 |
|------|------|--------------|
| 启动且有路径点 | 从最近路径点进入 Patrol | ✅ `Start()` 取最近点索引 |
| 玩家进入 `detectionRadius` | 切 Chase 追击 | ✅ `DetectPlayer()` + `Physics2D.OverlapCircle` |
| 玩家进入 `attackRange` | 停步并调用 `CreatATKTrigger1()` | ✅ `TickChase()` |
| 玩家超出 `loseTargetDistance` | 回最近路径点继续巡逻 | ✅ `ResumePatrolFromNearestPoint()` |
| 受击 | 暂停导航、保留击退、结束后恢复 | ✅ `wasHit` + `PauseNavigation()` + `Warp` |
| 无路径点 | Idle 不报错 | ✅ `patrolIndex < 0` 分支 |
| NavMesh 未烘焙 | MoveDirect 直线移动回退 | ✅ `isOnNavMesh` 守卫 |

**Play Mode 手测清单（需在 Unity 编辑器执行，本报告不覆盖实机运行）：**

1. `Tools → 怪物巡逻 → Create Patrol Demo Setup`（先选中怪物）后进入 Play。
2. 巡逻往返、追击切换、攻击触发、离开回归、受击暂停各验证 1 次（详见 `docs/怪物巡逻系统使用与配置文档.md` 第六节）。

### 3.2 交易系统（InventoryManager 静态验证）

| 用例 | 预期 | 核查结果 |
|------|------|----------|
| 购买合法物品 | 扣款 + 入包 + 事件触发 | ✅ 金额、堆叠、空槽分阶段规划 |
| 购买价格溢出（`buyPrice * count > int.MaxValue`） | 拒绝交易 | ✅ `long` 中间量 + 上限检查 |
| 背包缩容时非空槽 | 物品不丢失 | ✅ 缩容仅移除末尾空槽 |
| 卖出超量（`quantity < count`） | 拒绝 | ✅ 前置校验 |
| 金币溢出（`currentMoney + gain > int.MaxValue`） | 拒绝 | ✅ 上限检查 |
| 交易后 UI 刷新 | `onInventoryChanged` / `onMoneyChanged` | ✅ 交易成功后同步触发 |
